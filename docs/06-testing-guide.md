**预期结果**：

**预期结果**：

## 🐛 常见问题排查

### 问题 1：按钮点击无响应
**排查步骤**：
1. 检查浏览器控制台是否有JavaScript错误
2. 确认 `showSupplierDialog` 状态变量正常
3. 检查对话框组件是否正确导入

### 问题 2：数据库连接错误
**排查步骤**：
1. 确认数据库迁移是否执行成功
2. 检查表名是否正确（`order_lists` vs `product_lists`）
3. 验证外键约束是否正确设置

### 问题 3：供应商列表为空
**排查步骤**：
1. 检查数据库中是否有 `supplier_profiles` 数据
2. 确认供应商的 `is_active` 字段为 true
3. 检查供应商的认证状态

### 问题 4：实时聊天不工作
**排查步骤**：
1. 检查 Supabase Realtime 配置
2. 确认 WebSocket 连接正常
3. 验证 RLS 策略是否正确设置
