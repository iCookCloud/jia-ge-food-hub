# 聊天协商功能使用说明

## 🎯 功能概述

基于您的需求"买家可以分享报价单给供应商（平台认证的供应商用户），供应商修改价格或者确认，通过聊天窗口。双方确定后成为订单并交付"，我们已经完全实现了这个聊天协商系统。

### 核心特性
- ✅ 买家直接选择认证供应商分享货单
- ✅ 供应商通过聊天窗口提交报价并协商价格
- ✅ 实时聊天支持文本消息和价格提案
- ✅ 双方确认后自动生成订单
- ✅ 完整的协商状态跟踪

---

## 🚀 使用流程

### 第1步：买家创建货单
1. 在购物车页面添加商品
2. 点击"生成货单"按钮
3. 填写货单基本信息（名称、交货地址、特殊要求等）
4. 货单状态：`draft`（草稿）

### 第2步：分享给认证供应商
1. 在货单详情页面点击"分享给供应商"
2. 系统显示认证供应商列表，支持：
   - 按产品类别筛选
   - 按服务区域筛选
   - 按评分筛选
   - 关键词搜索
3. 选择一个或多个认证供应商
4. 可添加备注信息和回复截止时间
5. 确认分享，货单状态变为：`shared`（已分享）

### 第3步：供应商接收并报价
1. 供应商收到货单分享通知
2. 查看货单详情和商品清单
3. 提交初始报价，包括：
   - 各商品单价
   - 预计交货时间
   - 备注说明
4. 报价提交后自动创建聊天会话
5. 货单状态变为：`negotiating`（协商中）

### 第4步：聊天协商价格
1. 买家在协商页面查看所有报价
2. 选择感兴趣的供应商进入聊天
3. 双方可以：
   - 发送文本消息讨论细节
   - 发送价格提案（新的报价）
   - 接受或拒绝对方的价格提案
   - 实时查看价格变化历史

### 第5步：确认成交
1. 协商达成一致后，双方分别点击"确认当前价格"
2. 系统检测到买家和供应商都已确认
3. 自动生成正式订单
4. 货单状态变为：`confirmed`（已确认）
5. 后续进入订单履约流程

## 🗄️ 数据库结构

### 核心数据表
1. **order_lists** - 统一货单表
   - 支持状态：draft → shared → negotiating → confirmed → delivered
   
2. **supplier_quotations** - 供应商报价表
   - 支持价格协商记录（original_amount、current_amount）
   - 双方确认状态（buyer_confirmed、supplier_confirmed）
   
3. **quotation_items** - 报价明细表
   
4. **chat_negotiations** - 聊天协商记录表（新增）
   - 支持文本消息、价格提案、系统消息
   - 实时聊天记录存储

### 自动化触发器
- 供应商提交报价时自动创建协商会话
- 双方确认后自动生成订单
- 系统消息自动记录重要节点
